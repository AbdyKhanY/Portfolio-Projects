# Marketing Customer Segmentation Analysis (SQL)

## Project Overview
This project uses SQL in Google BigQuery to analyze customer demographics, spending habits, purchase behavior, and marketing campaign performance.

The analysis focuses on how customer attributes such as **age, income, marital status, and country** influence:

- Spending across product categories
- Purchase channels
- Campaign acceptance
- Response behavior
- Complaints

---

## Dataset Information
The dataset contains **2,240 rows** and **28 columns**.

### Dataset Columns
`ID, Year_Birth, Education, Marital_Status, Income, Kidhome, Teenhome, Dt_Customer, Recency, MntWines, MntFruits, MntMeatProducts, MntFishProducts, MntSweetProducts, MntGoldProds, NumDealsPurchases, NumWebPurchases, NumCatalogPurchases, NumStorePurchases, NumWebVisitsMonth, AcceptedCmp3, AcceptedCmp4, AcceptedCmp5, AcceptedCmp1, AcceptedCmp2, Response, Complain, Country`

---

## Key Analysis Performed
- Data exploration and validation
- Null value checks
- Age group and income group segmentation
