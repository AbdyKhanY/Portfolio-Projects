# Work Order Tracker Dashboard

### Live Workflow Monitoring & Reporting System

---

## 📌 Overview

The **Work Order Tracker Dashboard** is a live operational tracking system built using Google Sheets to monitor the full lifecycle of work orders — from creation to approval, execution, and closure.

The system was developed to improve operational visibility, ensure process control, and provide real-time reporting for ongoing facility maintenance activities.

---

## 🎯 Objective

* Track work orders across all workflow stages
* Improve visibility of operational activities
* Strengthen accountability and follow-up
* Provide real-time reporting for decision-making

---

## ⚠️ Problem Statement

Manual work order tracking often leads to:

* Delayed approvals
* Poor follow-up on tasks
* Unclear job status
* Lack of centralized reporting
* Reduced operational efficiency

---

## 💡 Solution

A structured tracking system was developed using Google Sheets with:

* A **Data Sheet** for live work order entry and updates
* A **Report Sheet** for dashboard visualization and insights

---

## 🔄 Workflow Process

1. Work Order Creation → **Pending for Approval**
2. Approval → **Approved**
3. Execution → Work Completed
4. Closure → **Closed**
